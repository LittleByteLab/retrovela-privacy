Retrovela 隐私政策

最后更新：2026年10月29日

应用：Retrovela: GBA Emulator（Android 包名：com.littlebytelab.retrovela.gba）

开发者及隐私联系：LittleByte Labs — littlebyte.lab@gmail.com

1. 适用范围

本政策说明 Retrovela 1.0 及本隐私政策网站的数据处理方式。LittleByte Labs 是开发者标识，不代表特定的已注册公司主体。Retrovela 是免费的 GBA 模拟器，运行由您自行提供并有权使用的兼容游戏，不内置商业 ROM。

2. 在设备上处理的信息

Retrovela 处理您选择的游戏文件及其 SHA-256，用于识别游戏、避免重复导入和关联进度。电池存档、三个即时存档槽位及保护性存档备份保存在应用管理的存储中。应用还保存游戏显示名称、原始文件名、封面缩略图、最近游玩时间、已授权文件夹引用、触控布局、手柄映射，以及语言、音量、画面模式等偏好。

手柄厂商、产品信息及输入设备描述符用于在本地区分手柄配置，不作为广告标识符使用。本地诊断日志可能包含文件路径、手柄信息、输入事件、错误及性能数据。

Retrovela 1.0 没有账号注册、广告、分析 SDK 或自动崩溃报告上传。应用不会主动将您的 ROM、存档、游戏库、偏好或诊断日志发送给 LittleByte Labs。我们不提供应用内云游戏或云存档服务，不出售您的信息，也不将其用于定向广告。本地处理并不意味着文件绝不会通过 Android 或您选择的服务离开设备。

3. 文件、权限及用户主动传输

您通过 Android 系统文件选择器选择 ROM、文件夹、封面和存档导入导出位置。选中的游戏文件会复制到应用管理的存储中；选择原始文件不意味着开发者能够访问它。封面会复制为有尺寸限制的缩略图。系统保存您授予的文档访问权限。

您选择的文件提供者可能是第三方云服务。打开云文件可能使该提供者下载文件，将存档导出到云位置可能使其上传文件。这些操作由您的选择发起，适用对应提供者的条款和隐私政策。导出内置开源归档只导出固定的应用源码材料，不包含您的 ROM、存档或日志。

游戏截图保存到系统图片集合的 Pictures/Retrovela。Android 9 及以下可能为此请求存储权限，较新版本使用 MediaStore。本版本不请求互联网、全文件管理、定位、相机、麦克风、广告 ID 或蓝牙扫描权限。手柄事件由 Android 输入系统提供。

4. Android 备份、设备迁移与照片同步

应用没有显式关闭 Android 系统备份。根据设备、备份设置、备份服务和存储限额，Android 或设备厂商可能备份应用文件及偏好，或将其迁移到另一设备。相册或文件提供者也可能独立同步截图或导出文件。

因此，即使 Retrovela 没有自行上传到开发者服务器，系统或提供者仍可能将数据传出设备。LittleByte Labs 不会通过本应用获得系统备份的访问权。您可以查看相关 Android、设备厂商、相册及云服务的设置和隐私政策，管理这些行为。

5. 保留、删除与您的控制

应用管理的游戏、进度、元数据及设置通常保留至可用操作将其改变，或 Android 的存储生命周期将其移除。您可以编辑显示名称、移除自定义封面、修改受支持的设置，并通过 Android 或相关文件提供者管理或撤销文件访问。撤销原始来源授权不会删除已经导入应用存储的副本。

当前版本没有账号或开发者运营的远程删除服务。若要移除全部应用私有数据，Android 提供“清除存储”和卸载操作。例如，可打开 Android“设置 → 应用 → Retrovela → 存储 → 清除存储（或清除数据）”；不同设备的菜单名称和路径可能不同。这些操作具有破坏性，可能移除已导入游戏、存档、元数据、设置和授权；请先导出需要保留的进度。仅删除原始 ROM 不一定移除导入副本或关联存档。我们不声称本版本提供按游戏逐项删除游戏库的入口。

导出存档、截图、原始文件及其他应用持有的副本，可能在清除数据或卸载后仍然存在。请使用对应文件、照片或云服务单独删除。系统备份及设备迁移副本适用相关提供者的保留和删除规则；清除应用数据不能保证删除所有备份。

6. 您主动发送给支持渠道的信息

这些邮件信息仅在您主动联系开发者时提供，不由 Retrovela 应用自动收集或上传。如果您向 littlebyte.lab@gmail.com 发邮件，我们会收到您的邮箱、消息及您选择提供的附件，用于调查问题、回复及处理相关隐私请求。请勿发送商业 ROM、密码、身份证件或无关私人文件；发送日志前请检查并移除私人文件名或路径。

支持通信通过我们的邮件服务提供者处理，适用其隐私规则。我们仅在处理请求、保留必要支持记录或履行适用法律义务所合理需要的期间保留通信，随后删除，但邮件服务的备份生命周期仍可能适用。您可以通过邮件请求删除支持通信；我们会评估并说明适用的保留要求。这不代表我们能远程删除您设备或您选择的服务中保存的数据。

7. 隐私政策网站

本网站使用静态页面。页面代码不添加分析、广告、Cookie、表单、远程字体或跟踪脚本。在 GitHub Pages 托管时，GitHub 可能依据其一般隐私声明处理 IP 地址及技术连接信息等请求数据。访问网站与应用的离线运行是不同活动。给我们发邮件会使用您的邮件服务，并适用其规则。

GitHub 一般隐私声明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement

8. 安全与儿童

我们使用 Android 应用存储及权限机制处理本地数据。任何存储或通信方式都不能保证绝对安全；请只导入、导出可信文件，并选择可信提供者。Retrovela 运行游戏不要求提供年龄、身份或账号信息，也不主动向儿童索取个人信息。如果您认为儿童向支持邮箱发送了个人信息，请联系以便我们核查和妥善处理。本说明不决定应用商店年龄分级。

9. 更新与联系

数据处理方式发生变化时，我们会更新本政策及上方日期，并在需要时通过适当的应用或商店提示说明重大变化。如有疑问或隐私请求，请联系 LittleByte Labs：littlebyte.lab@gmail.com。
